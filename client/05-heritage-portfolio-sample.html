How to use this sample

This is a worked layout, not the final book. Replace every bracketed placeholder with DS's own photographs, verified project facts, systems and warranties. The goal is simple: make 26 years of work look on paper as strong as it looks on site. Keep it private — it is sent one-to-one to a named decision-maker, never posted publicly.

All project names below come from public web research (November 2026). Validate every name, scope and technical detail with DS before print.

Production checklist — what DS must supply

  • 3 iconic projects to start (ideally 1 institutional, 1 corporate, 1 luxury residential)
  • 10–15 high-resolution photographs per project (exterior hero, detail, process/site)
  • Project facts: name, location, sector, client, year, scope, systems, outcome
  • Written permission to name any client or building where required
  • Confirmed warranty terms and technical standards
  • Factory and fleet photographs (1–2 each)
  • Founder/MD photograph on site and a short signed statement
  • Company logo files in print quality (vector preferred)

Writing rules — keep it credible

  1. Lead with proof, not adjectives. "42,000 m² installed" beats "world-class quality."
  2. Quantify wherever possible — area, years, programme, number of units.
  3. Never publish an unverifiable claim. If it cannot be shown, it does not go in.
  4. Name clients only with permission. Otherwise use "a leading Ghanaian university."
  5. Keep it private. One recipient, one purpose, one private channel.

Distribution protocol — how the portfolio is used

  1. Send only to a named decision-maker (Project Manager, Site Engineer, Owner or Lead Architect) of an active project.
  2. Send via private WhatsApp or email, with a short personal message — never as a mass broadcast.
  3. Record the send and recipient in the Option D introduced-project register (agreement Annex B).
  4. Never post the PDF, screenshots or project photographs on any public page, ad or social account.
  5. Update the portfolio after every significant completed project — it is a living credential, not a one-off brochure.
